# 🇧🇷 Macri Battle Stars - Introdução

Este é um projeto de jogo de luta 2D desenvolvido para ser o meu Trabalho de Conclusão de Curso (TCC), sendo este um critério obrigatório para graduação no curso superior de Engenharia de Software do Instituto Federal do Paraná (IFPR) - Campus Paranavaí.

A proposta deste TCC é apresentar um projeto de jogo separado em camadas, criando um Sistema Entidade-Componente (*ECS*) orientado a eventos utilizando o padrão arquitetural "*Event Bus*" e orientado a dados, utilizando arquivos .json para a criação facilitada de entidades.
